# Conditional future Confirmation analysis plan

This plan applies only after META1.6 completes new Development, freezes a materially modified candidate, and creates a new untouched reserve. It does not authorize running seeds 505/606 or any current reserve artifact.

## Unit of inference

The independent scientific unit is the biological landscape, not each budget-seed cell. Seven Ishizawa landscapes crossed with budgets and masks produce repeated measurements within landscapes.

## Primary analysis

1. Compute paired candidate-minus-comparator effects for every budget and mask within each landscape.
2. Aggregate those repeated cells into one prespecified landscape-level effect.
3. Report the seven landscape effects, their mean/median, signs, and a full heterogeneity plot.
4. Quantify uncertainty by a paired landscape-cluster bootstrap or an exact/small-sample paired procedure appropriate to seven clusters.
5. Present all raw paired cells as supporting evidence, never as 42 independent observations.

## Primary endpoint

Landscape-macro signed order>=3 support F1 under the frozen full-panel support definition. Precision, recall, AP, FDR, coefficient RMSE, response RMSE, stability, runtime, and exact-alias diagnostics are secondary.

## Multiplicity and interpretation

The single primary candidate-comparator contrast must be frozen. Secondary endpoints are descriptive unless a separate multiplicity plan is frozen. A held-out mask reserve on already-used landscapes is **internal held-out measurement-mask Confirmation**, not external biological validation. Diaz-Colunga remains the independent biological panel and its META1 result was negative.

## Failure rule

Failure of the new primary contrast ends the modified candidate. It does not authorize moving the <=50% boundary, retuning support thresholds, changing response scale, or reusing the same reserve for a new method.
