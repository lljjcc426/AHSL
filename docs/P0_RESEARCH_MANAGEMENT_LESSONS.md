## Reusable rules

1. Freeze the estimand, observation process and direct truth before selecting a
   model.
2. Require the strongest exact/classical projection before interpreting a
   structural inductive bias as ML value.
3. Distinguish representation truth from task truth: a real hypergraph does not
   automatically create a real prediction target.
4. Never treat unmeasured sets as negatives without a sampling/observation
   model.
5. A learned prior does not restore identifiability.
6. Compare at the correct protocol: supplied-candidate classification is not
   open-world retrieval.
7. Demand hypergraph necessity against graph, sparse regression, tensor, set
   and generic-solver alternatives.
8. Demand ML necessity separately from structural/theory necessity.
9. Price oracle labels and repeated-workload amortization before training a
   strategy learner.
10. A GO from topic discovery authorizes only the next kill-test, not model
    development.
11. Stop rules should target scientific claims, not only implementation errors.
12. Do not rescue a failed line through greater model complexity.

## Main correction for future programs

The project often established a mathematically valid structural restriction
before establishing a matching real task. Future parent directions should
reverse that order: accepted target and benchmark first, measurable classical
residual second, theory/ML interface third, implementation last.
