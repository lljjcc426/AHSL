# S0 risk register

| ID | Risk | Evidence | Consequence | S1 control / kill rule |
|---|---|---|---|---|
| R1 | interaction target changes with response scale/null | drug and fitness fields use non-equivalent contrasts | apparent structure may be definitional | freeze estimand; require sensitivity across scientifically defensible scales |
| R2 | random combination split leaks entity identity | Dango exposes random and gene-split modes; many works use random tuples | inflated interpolation result | gene/species/drug-disjoint and order-held-out splits are mandatory |
| R3 | only one strong order≥3 genetic dataset | Kuzmin yeast screen dominates the field | single-dataset paper, weak generality | require a second experimental route before committing to a concrete S1 project |
| R4 | Dango occupies the obvious HGNN-on-triples paper | direct 2026 collision with public code | incremental novelty | prohibit Dango cloning; target support validity, uncertainty, design, or transfer |
| R5 | classical sparse contrasts match ML | Möbius, hierarchical lasso, compressed sensing are strong | no ML necessity | compare first; kill if no residual on hard splits |
| R6 | pure higher-order effects violate heredity | >30% of measured trigenic interactions were not anticipated from doubles | hierarchical search misses discoveries | include non-hereditary baseline/class; report failure modes |
| R7 | HODDI labels are co-reports with constructed negatives | FAERS observational reporting and distribution-shifted negatives | confounding and shortcut learning | use only as secondary robustness route, not causal ground truth |
| R8 | combination space makes “negative” ambiguous | unmeasured is not non-interacting | false support metrics | evaluate against directly measured panels, not sampled nonedges |
| R9 | batch/assay effects mimic interactions | combinatorial biology data are heterogeneous | spurious support | use released replicate/QC fields and condition-aware splits where present |
| R10 | model predicts response but not support | black-box accuracy can hide wrong interactions | fails structure-learning definition | require support/effect or prospective-selection metrics |
| R11 | temporal finalist repeats sampled-negative classification | published audit shows mismatch with retrieval | scientifically weak evaluation | full/unconstrained retrieval or justified open-world approximation required |
| R12 | dynamics finalist has no real structure truth | EEG application has no validated hyperedges | synthetic main evidence | killed at S0 G7/G8 |
| R13 | protein-complex gold standards are incomplete and reused | CORUM/CYC overlap and curation incompleteness | uncertain negatives/leakage | killed unless time/species/assay-disjoint protocol exists |
| R14 | causal language exceeds interventions | observational hypergraph dependence is not causality | invalid scientific claim | reserve causal claims for randomized/identified designs |
| R15 | hypergraph-width theory is ornamental | no selected computation depends on decomposition width | incoherent paper | do not use GHW/FHW unless S1 finds a functional dependence |
| R16 | AHSL or CertPath is silently revived | shared vocabulary can obscure a reset | repeats closed work | explicit prohibited-topic list and branch isolation |

No hashes, repeated smoke tests, or speculative defensive code were added. The controls above correspond to observed methodological failure modes.
