# S3.0 Graph, Matrix and Tensor Collision

| candidate | strongest ordinary formulation | does hypergraph language add a recoverable target? | judgment |
|---|---|---|---|
| projection | clique cover, overlapping community, Bayesian graph compression | only if event identity has external labels or identifiable generative assumptions | no residual in current natural benchmarks |
| dynamics | sparse polynomial/tensor regression and nonlinear system identification | hyperedges name mixed-variable support; the computation remains feature-library support recovery | interpretation, not a separate estimator class |
| pooled assays | sparse GLM/compressed sensing/tensor interaction regression | support can be drawn as a hypergraph, but the inverse problem is unchanged | classical collision |
| censored groups | capture-recapture, occupancy model, latent class/community inference | exact event sets would be different, but are not identifiable from current data | target unavailable |
| protein complexes | pairwise scoring followed by MCL/MCODE/ClusterONE; NMF/co-clustering | overlapping output sets are already produced directly by graph clustering | hypergraph representation adds little algorithmic residual |
| marginals | hierarchical log-linear model, IPF, maximum entropy, tensor completion | high-order parameters are factor scopes, already native to statistics | classical collision |

Tensor decomposition is especially relevant when low-order moments are used to
recover latent mixture components. CP/Tucker uniqueness conditions and spectral
latent-variable methods already provide identifiability and sample-complexity
theory. Relabeling tensor factors as hyperedges does not create new science.

Protein-complex discovery is the decisive collision. The standard CF-MS
pipeline computes pairwise profile similarities, labels known positive and
negative protein pairs, trains a scorer, then clusters the resulting graph into
possibly overlapping complexes. ClusterONE already returns overlapping sets.
Any S3 proposal must improve a directly structural, assay-disjoint set metric;
no such residual was isolated.
