# S0 publication and program-depth audit

## Rank 1

### Minimum viable first paper

Benchmark-first structure-learning study across at least two real order≥3 intervention families; freeze interaction estimands; compare exact contrasts, sparse/hierarchical classical estimators, Dango where applicable, and one simple structure learner; use entity/order-disjoint splits; add one bounded theorem on identifiability, support recovery, or uncertainty; include a decisive pure-high-order/heredity ablation.

Difficulty: coding **medium**, compute **low–medium**, data engineering **medium**, theory **medium–high**, evaluation risk **medium–high**. Normal academic compute is sufficient because the first study need not score every combination globally.

### Program depth

- Project A: benchmark and estimand-consistent sparse support recovery on real combinatorial interventions.
- Project B: uncertainty/FDR and adaptive experimental design for costly combinations.
- Project C: cross-condition, cross-organism, or cross-domain support transfer; partial observations and order extrapolation.

### Publication fit

- Strong if method + real biology + rigorous evaluation: ICML/NeurIPS/ICLR, AISTATS/UAI, Nature Machine Intelligence/Patterns/Cell Systems, Bioinformatics/ISMB, PNAS interdisciplinary route.
- Plausible specialist: RECOMB, MLGenX, ACM-BCB, Genome Biology methods, PLOS Computational Biology.
- Weak: a single-dataset HGNN architecture paper or random-split regression improvement.

Successful work needs a jointly credible statistics/ML contribution and domain interpretation. Venue fit is not an acceptance forecast.

## Rank 2

### Minimum viable first paper

An open-world temporal set-event benchmark/protocol with full or search-controlled retrieval, simple point-process and heuristic baselines, unseen-group/entity splits, and one calibrated set-prediction/search guarantee.

Difficulty: coding **medium**, compute **medium**, data engineering **medium–high**, theory **medium**, evaluation risk **high**.

### Program depth

- Project A: correct open-world temporal hyperedge evaluation and baselines.
- Project B: calibrated directed set-valued point processes and efficient retrieval.
- Project C: node churn, partial observation, and domain-specific event semantics.

### Publication fit

Strong only if the work changes evaluation or provides a principled generative/search result: KDD, WWW, NeurIPS/ICML, TMLR. Merely improving sampled-negative AUC is weak.

## Selection rationale

Rank 1 has fewer but higher-quality structural labels, stronger evidence of irreducible high-order effects, a clearer statistics interface, and a coherent multi-project scientific question. Rank 2 has broader data availability but a denser modern literature and a more fragile evaluation convention. Therefore Rank 1 is selected for S1.
