## Semifinals and finalist

Four directions reached the semifinal audit. Only dynamic/incremental recursive query execution passes all gates. The reliable-data-workflow direction is not retained as a finalist because its exact novelty boundary and model independence fail; keeping it merely to manufacture a two-way final would overstate the evidence.
