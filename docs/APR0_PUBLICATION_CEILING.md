# AP-R0 publication ceiling

| Candidate | Minimal paper | Strong paper | Top-end paper | Community |
|---|---|---|---|---|
| A1 hybrid execution | focused current algorithm on real hybrid benchmark | integrated engine and independent workload | reusable execution abstraction plus guarantees | SIGMOD/PVLDB/ICDE |
| B1 verified workflows | failure taxonomy and executable repair strategy | state/recovery architecture with broad agents | model-robust specification/execution theory and system | ICSE/FSE, data/AI venues by task |
| C1 test generation | repository test method and real evaluation | verifier-guided system plus mechanism analysis | general test/specification abstraction | ICSE/FSE/ISSTA |
| D1 dynamic compilation | focused compiler/runtime policy | integrated compiler contribution across workloads | new compilation abstraction plus correctness/performance account | PLDI/ASPLOS/MLSys |
| E1 constraint synthesis | semantic repair/search method | integrated modeling-verification system | specification semantics/guarantees plus broad benchmark gains | CP/AAAI/IJCAI/KR |
| F1 fuzz repair | focused repair/search method | repair plus fuzz/differential system | general verified security-repair architecture | ISSTA/ICSE/FSE/security venues |

These ceilings are conditional. No minimal paper is currently authorized
because the first empirical premise, G5, failed or was unavailable. A top-end
claim cannot be merely a bigger model or more retries.
