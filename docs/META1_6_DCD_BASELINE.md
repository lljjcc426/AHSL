# META1.6 DCD baseline

The DCD-inspired comparator uses the same unknown-support Pi and Boolean row exchange. For each scenario it scores the product of the active Gram block's smallest eigenvalue and the positive part of its signed irrepresentability margin. A rank-deficient active block receives zero. Scenario scores are averaged.

This is a faithful recovery-condition adaptation, not a claim of reproducing the original DCD code or its free two-level design space. DCD is reported separately from A1–A8 because its objective is a geometric proxy rather than the simulated KKT probability.
