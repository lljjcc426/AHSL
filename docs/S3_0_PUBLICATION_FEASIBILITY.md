# S3.0 Publication Feasibility

## Result

No candidate is publication-feasible as the requested new learning/inference
project. Zero candidates reach semifinal or finalist status.

| possible output | evidence available now | venue level plausibility | why it is not S3.1 |
|---|---|---|---|
| negative benchmark audit of projection reconstruction | clear distinction between natural and author-generated projection; exact ambiguity counts | workshop, position or benchmark note | needs a new naturally projected dataset and independent event gold for a full empirical paper |
| identifiability note for pairwise projection | elementary exhaustive counts plus active COLT theory | insufficient alone | recent theory already gives sharper random-model thresholds |
| real-dynamics benchmark critique | strong naturality/gold mismatch across current methods | perspective or domain methods note | no independent real support labels, so no method can be adjudicated structurally |
| assay-disjoint protein-complex benchmark | CORUM/Complex Portal and public proteomics make construction conceivable | potentially TMLR/data-resource/domain venue if provenance can be made rigorous | requires substantial benchmark curation; classical and modern baselines already dominate the inference task |
| MNAR partial-group-event benchmark | scientifically meaningful partial-identification question | potentially strong after paired sensing data exist | required full-event calibration data were not found and would likely require new collection |

## Compute, data and theory

Public CF-MS, CORUM and hu.MAP resources make a first audit computationally
feasible without a wet lab. Feasibility alone is not a GO signal: the residual
would be benchmark provenance and positive-unlabeled evaluation, while the
meaningful set inference is already addressed by graph clustering, NMF and
integrated complex pipelines.

Projection and dynamics possess viable theorem interfaces—recovery thresholds,
equivalence classes, sparse support sample complexity and excitation—but these
interfaces are already occupied and do not repair the missing real structural
gold. Censoring has a partial-identification interface, but the observation
mechanism is not calibrated in a qualifying benchmark.

## Decision implication

S3.0 should be frozen as a no-go rather than converted into a model paper. A
future reopening would require new external evidence satisfying both:

1. two real routes, with at least one assay/sensor-disjoint A/B structural gold;
2. a precisely stated residual not solved by clique/community inference,
   tensor/matrix factorization, sparse system identification, compressed
   sensing or current domain pipelines.
