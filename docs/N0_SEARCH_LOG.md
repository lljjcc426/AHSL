## Protocol

2. For a promising candidate, add `learned`, `neural`, `reinforcement learning`, `algorithm selection`, `exact`, `certificate`, `benchmark`, and the exact structural object.
3. Open the closest primary paper and inspect methods, experiments, artifacts, and limitations.
4. Search a direct collision query combining problem + learned object + theory object.
5. Audit a public benchmark before scoring.
6. Stop a family when a hard gate is clearly failed; do not search for decorative variants.
