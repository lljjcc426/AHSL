# P0 theory-only pivot audit

## Why a theory pivot is evidence-based

The project repeatedly found that native hypergraph mathematics remained useful
after ML necessity failed. Exact connected-subtree DP was a real algorithmic
asset; CertPath produced exact attainability and robust-certificate statements;
R0 found active GHD/FHD theory and verifiable exactness even though learned
strategy selection failed. Recent work further strengthens approximation,
parameterized exact computation, incrementality and rerootability.

## Selected theory-centered program

**Certified reusable hypertree decompositions for evolving query and constraint
hypergraphs.**

The core object is a verified decomposition, not a prediction. The program asks
how to compute, canonicalize, reroot, update and reuse HD/GHD/FHD witnesses while
controlling width increase and update cost. It connects active mathematical
questions to HyperBench and downstream CQ/CSP structure without requiring a
factor-execution or supervised-learning benchmark.

## Three-project depth

1. **Canonical/reusable witnesses:** characterize equivalence, rerootability and
   succinct representation of useful decomposition families; give a verifier
   and exact small-instance oracle.
2. **Dynamic maintenance:** derive update-sensitive algorithms and lower bounds
   for edge/vertex/scope changes, with guarantees on width inflation and
   recourse.
3. **Certified execution interface:** determine when maintained decompositions
   improve CQ/CSP evaluation, separating structural certificate quality from
   engine-specific cost.

These are connected but not an artificial split: they concern representation,
dynamic algorithms and downstream consequences respectively.

## Why ML is auxiliary

Heuristics may rank separators or update moves only after a measurable residual
exists. Every output remains independently verified. ML is not named in the
first theorem, first benchmark or first kill-test. This avoids repeating R0's
generic solver-learning problem.

## First kill-test

Before implementing a new decomposition algorithm, freeze 2--3 precise theorem
questions and compare them with the newest exact, LP, FPT, incremental and
rerootable results. Continue only if at least one nontrivial statement is not a
direct corollary and its witness/counterexample can be checked on a bounded
HyperBench subset or generated minimal instances.
