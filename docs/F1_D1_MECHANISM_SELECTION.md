# F1-D1 mechanism selection

No mechanism is selected. Verification-aware search, semantic conservation, multi-location localization, and counterexample refinement remain hypotheses, not implemented methods.

The selection trigger is a concentrated actionable F3/F4/F5 mechanism under the frozen baseline. Infrastructure failure cannot justify any of them. After baseline execution, candidate predictability will first be tested using permitted signals such as crash class, patch pattern, changed scope, public tests, and candidate traces; no ML classifier is planned unless simple analysis fails.
