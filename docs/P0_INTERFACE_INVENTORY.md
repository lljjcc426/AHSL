# P0 interface inventory

Strong coupling requires both a materially necessary ML component and a native
hypergraph-theoretic concept that changes the objective, guarantee or
complexity. A hypergraph input format or HGNN architecture alone is insufficient.

## Untested versus unjustified

- **Category A, not tested but positively motivated:** I11 as pure query
  algorithms/learning theory; I13 as decomposition algorithms/theory.
- **Category B, evidence-neutral:** none. After the completed gates, the burden
  of proof is higher than neutrality for any new strong-coupling proposal.
- **Category C, untested but strongly threatened:** I7 and I9 as ML interfaces;
  their generic analogues are active, while no real hypergraph-essential
  residual is measured.
- **Category D, effectively covered:** I1--I6, I8, I10 and I12.

No Category-A item is Q1. Therefore the inventory cannot support P0-A.
