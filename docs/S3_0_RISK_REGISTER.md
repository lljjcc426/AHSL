| ID | risk | affected families | evidence | consequence | S3.0 treatment |
|---|---|---|---|---|---|
| R1 | a real hypergraph is projected by the benchmark author, not by nature | projection | dominant reconstruction evaluations begin with known hyperedges | false reality claim | fatal: fail G2 |
| R2 | many hypergraphs induce the same pairwise projection | projection | exact small-case enumeration; theoretical impossibility/threshold literature | exact labels are prior-dependent | fatal unless a meaningful equivalence target is declared |

| R5 | hidden state or insufficient excitation invalidates system identification | dynamics | state sufficiency and excitation are required assumptions | unstable or spurious couplings | fail G6 on current real routes |

| R7 | unknown MNAR detection aliases event composition and detection propensity | censored events | visible/tagged entities have different detection probabilities | severe partial identification | fail G5 |
| R8 | no paired partial/full event corpus exists at useful scale | censored events | screened ecology/privacy routes lack independent complete membership | direct evaluation impossible | fail G3/G4/G10 |
| R9 | curated complexes are positives, while uncurated sets are not negatives | protein complexes | CORUM inclusion requires evidence and is incomplete | biased precision/recall and false negatives | restrict claims to positive-unlabeled audit; still fail clean evaluation |

| R12 | low-order marginals leave an unobserved operator kernel | marginals | multiple tables/log-linear interactions share identical marginals | maximum entropy selects rather than identifies | fail G5/G7 |
| R13 | a neural prior masks non-identifiability | all | likelihood-equivalent structures can receive different learned scores | unsupported exact-recovery claim | no model authorized; demand an observation-level identifiability statement |
| R14 | downstream prediction substitutes for structural validation | dynamics, pooled, complexes | common real-data evaluations score response or enrichment | wrong estimand | fail G9 |
| R15 | closed S1.0/S2.0 lines are silently reopened | pooled, event prediction | same effect-support or future-event target reappears under new vocabulary | repeats a settled failure | no reopening without new external truth |

No mitigation in this register turns a failed candidate into a semifinal. The
remaining mitigations would require new assay-disjoint gold, calibrated sensing
or a different scientific estimand, all outside S3.0.
